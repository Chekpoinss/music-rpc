# Изменения

## 0.3.0 — Linux с графическим интерфейсом

- GTK 4: Application ID, выбор источников, приоритет, поиск обложек и журнал в одном окне.
- Установка в домашний каталог без sudo и ярлык Music RPC в меню приложений.
- Фоновый запуск с настройками GUI; отдельный скрипт удаления с сохранением настроек.
- Архивы Linux x64 и Windows x64 с контрольными суммами SHA-256.
- Обновлён README с установкой, диагностикой и ограничениями обеих платформ.

Linux использует MPRIS / playerctl; для Apple Music нужен совместимый клиент, например Cider. Закрытие GTK-окна останавливает передачу статуса.
